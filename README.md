# 遗迹守卫战 · M1 灰盒原型

依据《宝可梦机制迁移设计 V0.1》实现的可玩塔防原型：收集 → 养成 → 对战 → 社交四层机制全部落地。
纯原生 HTML/Canvas/JS，无构建步骤：直接用浏览器打开 `index.html`（或 `python3 -m http.server`）。

## 已实现的机制

| 层 | 设计文档条目 | 原型实现 |
|---|---|---|
| 收集 | 英雄图鉴 | 阵营 × 职业编排，背景故事、技能演化页；战役首通 / 无尽 15 波 / 召唤 / 阵营均可点亮 |
| 收集 | 局内「支配」捕捉 | 支配头环每局限购 2 个、售价 240；精英血量 < 20% 可用；读条期间被己方误杀或漏怪则失败并返还 50%；成功后转化为限时 3 波、属性 ×0.6 的防御单位；首领与飞行单位免疫 |
| 收集 | 异化英雄 | 1/512，原创配色 + 星芒，零数值差异 |
| 养成 | 资质（IV） | 攻击/防御/灵巧 0–15，单项 0–5%，总和封顶 6% |
| 养成 | 历练（EV） | 每参战 2 波得 1 点，进攻/生存/功能三线，单线 10、总和 15，局内按 50% 生效，每周免费洗点 3 次 |
| 养成 | 专精熟练度 | Lv3 专属台词、Lv5 局内名牌框、Lv7 结算演出、Lv10 冠名 |
| 对战 | 攻击 × 护甲矩阵 | 4×4 矩阵，S2 赛季词缀「重甲魔抗 +25%」，克制/抵抗浮字提示 |
| 对战 | 心跳型随机 | 神符随机刷新（狂暴/急速/财富/凝滞）、暴击装备、支配血线博弈 |
| 社交 | 英雄租借 | 模拟好友，24 小时、同时最多 2 名；上架后当天自己不可用，可获租金 |
| 社交 | 阵容分享码 | 12 位编码（英雄 + 出装 + 塔位 + 关卡 + 校验），模拟演武场以标准练度复现 |
| 社交 | 赛季阵营专属 | 曦光 / 暗渊各 2 名专属英雄，赛季原初版标识 |
| 验证 | 失败信号 | 「验证」页按文档阈值逐条显示本机埋点（图鉴打开率、支配购买率、单一攻击类型通关率等） |

所有 `[PLACEHOLDER]` 数值集中在 `js/data.js`，便于 M1 调参。

## 文件

- `js/data.js` 英雄、敌人、关卡、矩阵、全部可调参数
- `js/battle.js` 战斗引擎（主循环、克制结算、支配、神符、震慑）
- `js/meta.js` 局外系统与存档（localStorage）
- `js/ui.js` 界面与结算
- `js/art.js` / `js/sfx.js` 程序化美术与合成音效（全部原创，无外部素材）
